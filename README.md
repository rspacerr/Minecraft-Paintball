# Paintball

Minecraft Plugin enabling users to play versions of Paintball. 

> [!WARNING]
> This plugin is currently under development and release has not been finalized. Bugs are expected.

## Quickstart
Download the .jar file corresponding to your server version and insert in `plugins` folder.
Once loaded, assign players to teams with

```/changeteam <TeamName> <player>```

Toggle gamemode with

```/gametype [PAINTBALL/QUICKFIRE/FROSTBITE]```

Finally, start the game with

```/start```

## Gameplay

### Paintball
The default paintball gamemode currently offers a single weapon with a set cooldown. More customization features are planned in the future.
Last team alive wins.

### Quickfire
A faster paced version of paintball with quickcharge crossbows, where players have fewer hearts of health by default. Each crossbow shot deals one heart.
Last team alive wins.

### Frostbite
Tagging players with a bow freezes them in place, but frozen players can be revived by unfrozen teammates with a punch. Last team alive wins.
